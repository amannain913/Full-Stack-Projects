# Experiment 1.4.1 + 1.4.2 — Interactive Calendar, Performance & Testing

## Aim
Implement an interactive calendar for scheduling posts and optimize/test the UI.

## Features
- Seven-day scheduling calendar
- Posts mapped to dates and time slots
- Drag-and-drop rescheduling
- Add scheduled post interaction
- `React.memo` for event components
- `useMemo` for derived data
- `useCallback` for stable handlers
- Vitest + React Testing Library test examples

## Run
```bash
npm install
npm run dev
```

## Run tests
```bash
npm test
```
