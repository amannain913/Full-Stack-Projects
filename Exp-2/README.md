# Experiment 1.2.1 — Redux Toolkit State Management

## Aim
To design and implement centralized state management using Redux Toolkit for managing posts and platform-related data.

## Implemented Features
- Central Redux store
- Separate posts and platforms slices
- Normalized post state (`byId` + `allIds`)
- CRUD-style add/delete actions
- Draft state management
- Global state accessed with `useSelector` and `useDispatch`

## Run
```bash
npm install
npm run dev
```
