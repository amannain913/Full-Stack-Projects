# Experiment 1.1.1 — Dynamic Multi-Platform Post Composer

## Aim
To design and develop a dynamic post composer interface supporting multiple platforms with constraint validation.

## Implemented Features
- Platform selection for X/Twitter, Instagram and LinkedIn
- Real-time character counters and limits
- Hashtag validation
- Media attachment
- Live warning/error indicators
- Responsive UI

## Run in VS Code
```bash
npm install
npm run dev
```

Open the local URL shown by Vite in the terminal.

## Expected Outcome
A working, responsive post composer with platform-specific validation and real-time feedback.
